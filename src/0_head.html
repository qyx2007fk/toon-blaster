玩法说明

手机/平板：左半屏拖动 移动 · 右半屏滑动 转视角 · 屏幕按钮 射击/跳/冲刺/换弹/切枪/暂停
电脑：WASD 移动 · 空格 跳跃 · Shift 奔跑 · Q / 右键 冲刺（短暂无敌）
鼠标瞄准 · 左键 射击 · R 换弹 · 1-5 / 滚轮 切换武器 · Esc 暂停
关卡：5 个主题世界，每关 3 波敌人 + 1 个 Boss，过关后三选一天赋。通关后进入无尽模式。
武器：泡泡手枪 / 散弹喷子 / 冲锋水枪 / 火箭泡泡 / 激光炮，在关卡里找到发光的武器拾取。
技巧：打敌人头顶会暴击；连续击杀提升分数倍率；射击红色油桶引发爆炸；
跳板弹射、加速带冲刺、传送门瞬移、治疗台回血；小心地刺、电锯、岩浆和火焰喷口！
Boss 的冲击波和弹幕贴地飞行，跳起来就能躲开。
