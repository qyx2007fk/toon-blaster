# Toon Blaster 卡通大乱斗

卡通风格的 3D 第一人称射击小游戏，基于 [Three.js](https://threejs.org/)，单个 HTML 文件，浏览器直接打开即可游玩（需联网加载 Three.js）。

## 玩法

- 5 个主题关卡：青青草原、沙漠峡谷、冰雪王国、糖果乐园、熔岩火山；每关 3 波敌人 + 1 个三阶段 Boss，通关后进入无尽模式
- 5 把武器：泡泡手枪、散弹喷子、冲锋水枪、火箭泡泡、激光炮
- 8 种敌人：果冻、兔兔、大块头、吐吐、炸弹君、蝙蝠、分裂果冻、小果冻
- 机关陷阱：跳板、加速带、地刺、电锯、爆炸桶、岩浆、冰面、火焰喷口、传送门、治疗台
- 7 套皮肤（金币解锁）、13 种天赋、临时道具、连击倍率、雷达小地图

## 操作

| 按键 | 功能 |
| --- | --- |
| WASD | 移动 |
| 空格 | 跳跃 |
| Shift | 奔跑 |
| Q / 右键 | 冲刺（短暂无敌） |
| 鼠标左键 | 射击 |
| R | 换弹 |
| 1-5 / 滚轮 | 切换武器 |
| Esc | 暂停 |

## 运行

直接用浏览器打开 `index.html`，或启动本地服务器：

```sh
python3 -m http.server 8080
```

然后访问 http://localhost:8080 。

## 开发

源码拆分在 `src/` 目录中，修改后运行 `./build.sh` 重新生成 `index.html`。
